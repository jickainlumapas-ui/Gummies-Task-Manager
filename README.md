## Project Description

Gummies is a simple Personal Task Manager developed using Laravel.

The purpose of this project is to demonstrate the use of Laravel's:

- Routes
- Controllers
- Models
- Database
- Blade Views

The system allows users to create, view, edit, delete, and update the status of personal tasks.

This project uses SQLite as the database, so it does not require XAMPP or MySQL.

## Features

### Add Task

Users can create a new task with:

- Task name
- Description
- Status
- Due date

### View Tasks

Users can view all saved tasks on the main task manager page.

### Edit Task

Users can edit the information of an existing task.

### Delete Task

Users can delete a task from the task manager.

### Update Status

Users can change a task's status between:

- Pending
- Completed
